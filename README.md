Este é um projeto Next.js inicializado com create-next-app.

Aplicação web desenvolvida como projeto pessoal utilizando tecnologias modernas do ecossistema React, com foco em performance, escalabilidade, tipagem forte e qualidade de código.

Este projeto foi criado para aplicar boas práticas de arquitetura front-end, testes unitários e organização de código em aplicações reais.

🛠️ Tecnologias Utilizadas

⚡ Next.js

⚛️ React

🔷 TypeScript

🎨 SCSS

🧪 Jest

🔍 React Testing Library

🎯 Objetivo do Projeto
Estruturar uma aplicação escalável
Organizar estilos com SCSS modular
Realizar testes unitários

📁 Estrutura do Projeto

src/app/ – Estrutura de rotas (App Router - Next.js)

src/assets/images/ – Imagens e arquivos estáticos

src/components/ – Componentes reutilizáveis

src/consts/ – Constantes globais da aplicação

src/helpers/ – Funções auxiliares

src/lib/ – Configurações e integrações externas

src/styles/ – Arquivos SCSS globais e módulos

src/types/ – Definições de tipos e interfaces
